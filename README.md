# IE3142 DevOps Security – NodeGoat DevSecOps Project

## Project Overview

This project applies DevSecOps practices to OWASP NodeGoat, an intentionally vulnerable Node.js/Express application using MongoDB.

The project includes:

- Docker-based local deployment
- STRIDE threat modelling and risk assessment
- Secure coding and vulnerability remediation
- SAST using Semgrep
- CI/CD security automation
- Dependency, secrets and container-image scanning

## Application

- OWASP NodeGoat
- Node.js / Express
- MongoDB
- Docker / Docker Compose
